# HAQSETU AI/ML Model

This directory contains the AI/ML model development and experimentation work contributed to the HAQSETU project.

## Contents

- data/
  - classifier/
  - legalstuff/
  - processed/
  - raw/
- notebooks/
- src/
  - chunking.py
  - rag.py
  - retrieval.py
  - test_retrieval.py

## Purpose

The work in this directory covers:

- Dataset preparation and preprocessing
- Intent classification
- TF-IDF feature processing
- Legal corpus preparation
- Retrieval experiments
- RAG experimentation
- Model testing and evaluation

The notebooks contain the associated data-processing, model-rating, testing, and dataset-splitting experiments.

## Relationship to the Application

This directory is preserved as the project's AI/ML development contribution.

The currently integrated production application lives under:

ps25/backend/triage/

The model work in this directory is kept separate from that application pipeline so that the experimental/model-development code and the integrated backend remain clearly separated.
